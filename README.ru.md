# Worse Code (WC)
# Мы очень рекомендуем использовать BASIC PACK со вкладки Релизов!

**Маленький язык программирования, который можно подстроить под себя.** Переименовывай любые команды, открывай настоящие окна, рисуй на холсте и пиши игры: всё это из обычных текстовых файлов и одного интерпретатора на Python.

`Стабильная: Version 1b` · `В разработке: Version 2a` · Написан на Python · Сделан на Windows · [English version](README.md)

## Возможности

- Простой читаемый синтаксис: переменные, `if / else`, циклы, списки, выражения.
- **Любую команду можно переименовать** в небольшом JSON-файле.
- **WCSG** (WC Standard GUI): готовые окна (ошибка, вопрос, ввод, пустое...), чёрное окно консоли и холст *MiniPaint* с чтением клавиш.
- Можно писать настоящие игры: полная змейка примерно в 50 строк ([examples/snake](examples/snake)).
- **Создатель .exe**: перетащи папку на скрипт и получи программу для Windows.
- **Плагины**: менеджер плагинов добавляет в проект команды и функции, категории Standard, User и Hotfix.
- Интерпретатор это обычный Python без обязательных сторонних пакетов (Pillow нужен только для иконок `.jpg`, PyInstaller только для создателя .exe).

### Номера версий

- Версия это число и буква: `Version 1a`, `Version 1b`, `Version 2a`. Число обозначает поколение языка, буква выпуск внутри него. Самый новый релиз без пометки *Pre-release* считается стабильным.
- Пробная сборка следующей версии называется `<текущая>-<следующая>-devNN`, например `Version 1b-2a-dev01`. Она публикуется как **Pre-release** (*Developer Beta*) и может быть нестабильной.
- Теги в Git повторяют названия: `version-1b`, `version-1b-2a-dev01`.

## Быстрый старт

**Требования:** Python 3.8 или новее с tkinter (он есть в официальном установщике для Windows). Основная платформа Windows.

Скачай WCBP с вкладки Releases

Программа это текстовый файл в кодировке UTF-8 с расширением `.wc`:

```
python wc.py my_program.wc
```

Ключ `--pause` оставляет окно консоли открытым в конце. В Блокноте выбирай «Все файлы» при сохранении, иначе получится `my_program.wc.txt`.

## Язык за пять минут

В примерах стандартные слова. Любое из них можно поменять (см. [Сделай язык своим](#сделай-язык-своим)).

**Вывод, переменные, ввод**

```
set x = 5
set name = "Аня"
say "Привет, " + name
say x * 2
ask answer
```

`ask` читает строку: число становится числом, всё остальное остаётся текстом. Выражения это выражения Python: работают `+ - * / ( )`, `str()`, `len()`, `range()` и другие. В переменной `year` лежит текущий год.

**Условия** (`==  !=  <  >  <=  >=  and  or  not  in`)

```
if x > 3
    say "много"
else
    say "мало"
end
```

Каждый блок заканчивается словом `end`. Команды `elif` пока нет: вложи ещё один `if` в `else`.

**Циклы**

```
set n = 0
makeuserdoright n < 3
    set n = n + 1
    say n
end

draw i in range(3)
    if i == 2
        forcequit
    end
    say i
end
```

`makeuserdoright` повторяет, пока условие верно, `draw x in список` перебирает список, `forcequit` выходит из ближайшего цикла.

**Списки и случайные числа**

```
set body = [[1, 1], [2, 1]]
make body.append([3, 1])
set body[0] = [9, 9]
set a, b = 1, 2
set dice = random(1, 6)
say len(body)
```

`make выражение` вычисляет выражение и не выводит результат: так вызывают методы списков.

**Прочее**

```
sleep 1.5
# комментарий, можно и после команды
exit
```

## Команды

| Ключ в конфиге | Слово по умолчанию | Что делает |
|---|---|---|
| `say` | `say` | вывести значение |
| `set` | `set` | присвоить: `set x = 5`, `set a, b = 1, 2`, `set list[0] = 5` |
| `ask` | `ask` | прочитать число или текст в переменную |
| `if` / `else` / `end` | `if` / `else` / `end` | условия и конец любого блока |
| `while` | `makeuserdoright` | цикл, пока условие верно |
| `for` | `draw` | цикл по списку |
| `break` | `forcequit` | выйти из ближайшего цикла |
| `do` | `make` | вычислить выражение без вывода |
| `load` | `load` | подключить модуль: `load standrt_gui` |
| `gui_start` / `gui_stop` | `wcsgstart` / `wcsgstophere` | начало и конец зоны WCSG |
| `force_noecho` | `force_noecho` | скрыть консоль насовсем, всё идёт через WCSG |
| `canvas` | `minipaint` | открыть холст |
| `text` | `speaksymbols` | написать текст на холсте |
| `comment` | `#` | символ комментария |
| `prompt` | `> ` | приглашение для `ask` |

Фиксированные слова: `sleep`, `exit` / `quit`, `clear`, `rect`, `circle` и функции `random(a, b)`, `waitkey(мс)`.

## Сделай язык своим

Скопируй `wc_config.example.json` в `wc_config.json` и оставь только слова, которые хочешь поменять:

```json
{
  "say": "speak",
  "set": "to",
  "ask": "whatnumber",
  "comment": "//"
}
```

Настройки накладываются по слоям: встроенные значения, потом `wc_config.json` рядом с `wc.py`, потом `wc_config.json` рядом с твоей программой (у каждого проекта могут быть свои слова). Команда должна быть одним словом, все команды должны различаться, и ни одна не может начинаться с символа комментария.

## WCSG: окна, консоль и холст

```
load standrt_gui
wcsgstart
Error_window ] where center ] speak ("Тест") ] fontspeak "Arial Black" ] windowicon "/error.png"
wcsgstophere
```

Модуль подключается один раз командой `load standrt_gui` (работает и `standart_gui`). Строки окон пишутся между `wcsgstart` и `wcsgstophere` и выглядят так: `Пресет ] параметр значение ] параметр значение`. Окна модальные: программа продолжается, когда окно закрыто.

**Пресеты**

| Пресет | Что это | Ответ (через `save`) |
|---|---|---|
| `Error_window` | красный крестик, OK | |
| `Warning_window` | жёлтый треугольник, OK | |
| `Info_window` | синяя буква i, OK | |
| `Success_window` | зелёная галочка, OK | |
| `Message_window` | просто текст | |
| `Question_window` | Да / Нет | `"yes"` или `"no"` |
| `Confirm_window` | OK / Отмена | `"ok"` или `"cancel"` |
| `Input_window` | поле ввода | введённое (число, если это число) |
| `Blank_window` | большое пустое окно, любая клавиша закрывает его | имя клавиши, например `"Return"` |

**Параметры**

| Параметр | Значение | Что делает |
|---|---|---|
| `where` | `center` `left` `right` `top` `bottom` `topleft` `topright` `bottomleft` `bottomright` | место на экране |
| `speak` | выражение | текст окна |
| `title` | выражение | заголовок окна |
| `fontspeak`, `fontsize` | `"Arial Black"`, `14` | шрифт |
| `windowicon` | `"/error.png"` | картинка возле текста, путь от папки программы, уменьшается примерно до 56 px. PNG и GIF работают сразу, для JPG нужен Pillow |
| `bg`, `fg` | `"white"`, `"#202020"` | цвет фона и текста |
| `size` | `"400x200"` | размер окна |
| `alpha` | от `0.1` до `1` | прозрачность |
| `button` | `"Play"` | своя кнопка, можно повторять. Любая кнопка закрывает окно, а её текст попадает в `save` |
| `save` | имя переменной | сохранить ответ |

Флаги (пиши без значения или с `yes` / `no`): `stndrt_icon_destroy` (убрать иконку-перо из заголовка), `resizable`, `draggable` (тянуть за любое место), `noborder`, `topmost` (по умолчанию включён), `anykey` (любая клавиша закрывает окно).

```
Blank_window ] button "Play" ] button "Quit" ] save choice
```

**Консоль внутри зоны.** Между `wcsgstart` и `wcsgstophere` настоящая консоль скрыта: `say` пишет в чёрное окно *WC Console*, а `ask` показывает поле ввода (Enter или кнопка Done). Когда зона заканчивается, окно закрывается по клавише или клику. `force_noecho` скрывает консоль на всю программу. В конце работы и при ошибке консоль всегда возвращается. Скрытие работает в классической консоли Windows, а Windows Terminal может оставить своё окно на экране.

**Холст.** Внутри зоны:

```
minipaint 600, 400, "black"
clear
rect 10, 10, 100, 50, "green"
circle 300, 200, 30, "red"
speaksymbols 10, 360, "Счёт: 3", "white", 18
set key = waitkey(120)
```

`waitkey(мс)` ждёт столько миллисекунд и возвращает последнюю нажатую за это время клавишу (`"Up"`, `"Left"`, `"space"`, `"a"`...) или пустую строку. Это «тик» игры. Если закрыть окно холста, программа остановится.

## Сборка .exe для Windows

*Этот инструмент пока в бета-версии.*

1. Положи программу в папку с файлом `start.wc`.
2. Перетащи папку на `wc_exe_maker.py`.
3. Забери созданную папку `<имя>_release`: в ней твои файлы, интерпретатор и `.exe`.

`.exe` ищет Python на компьютере. Если его нет, а в папке программы лежит `python_windows.exe` (официальный установщик Python с python.org, переименованный), он спрашивает разрешение, тихо ставит Python для текущего пользователя (права администратора не нужны) и запускает программу. Без установщика показывает окно «Python is required, but not installed». PyInstaller создатель ставит сам один раз. Не клади `.exe` в git (установщик Python к тому же слишком большой для загрузки через сайт), прикрепляй их к релизу на GitHub.

## Плагины

Плагины (**бета для разработчиков**, их ждёт Version 2a) добавляют команды и функции без правки ядра. Запусти `python wc_plugin_manager.py`, выбери папку проекта и ставь нужное: **Standard** (стандартные: `pause`, `mathplus`, `beep`, `storage`), **User** (пользовательские) и **Hotfixes** (хотфиксы). Менеджер сам правит `wc_config.json` проекта и при необходимости добавляет в `wc.py` крючки для плагинов. Как написать свой: [docs/PLUGINS.ru.md](docs/PLUGINS.ru.md).

## Безопасность

Плагины это тоже код Python, поэтому ставь только те, которым доверяешь.


WC вычисляет выражения через `eval` и `exec` из Python. Поэтому программа `.wc` может делать всё, что умеет скрипт на Python. Запускай только программы, которым доверяешь.

## Ограничения

- Пока нет собственных функций и `elif`.
- В `draw` можно указать только одну переменную.
- Скрытие консоли и создатель .exe рассчитаны на Windows.
