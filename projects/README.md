# Projects / Проекты

Put your own WC programs here, one folder per program:

```
projects/
  my-game/
    start.wc          <- the entry point
    wc_config.json    <- optional: your own keywords for this project
    icon.ico          <- optional: icon of the .exe
    error.png         <- optional: any assets
```

Положи сюда свои программы на WC, по одной папке на программу. Точка входа это `start.wc`, а свои слова для проекта можно хранить в `wc_config.json` рядом с ним.

Run / Запуск: `python wc.py projects/my-game/start.wc`
